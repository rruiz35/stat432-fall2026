Question 1: Training and test error

Using seed 43202, I generated one fixed 100 x 20 matrix, set beta[j] = 0.4^sqrt(j), and generated 200 independent training/test response pairs. Each model included an intercept and the first m predictors.

Results. Training MSE is nonincreasing within every simulation run. Average training and test MSE follow the expected bias-variance pattern: training error decreases as predictors are added, while test error generally decreases at first and then levels off or rises as estimation variance increases. The simulation averages are close to the theoretical curves below; the single-run test curve is visibly noisier because it contains one realization of test-response noise.

With H_m the hat matrix and B_m^2 = ||(I-H_m)mu||^2, the theoretical curves are

E(train MSE | X) = Bm2/n + 1 - (m+1)/n

E(test MSE | X) = Bm2/n + 1 + (m+1)/n

The training curve alone cannot select the predictor count: it rewards flexibility through the negative (m+1)/n term, while test error balances decreasing approximation bias against increasing estimation variance.

The required simulation code uses QR/SVD least squares and overlays average, theoretical, and one-run test curves.

Question 3: The optimism correction

Using symmetry and idempotence of H, the training residual is (I-H)mu + (I-H)epsilon. Therefore:

E(train MSE | X) = B2/n + sigma2(1 - (p+1)/n)

For an independent test response, the noise is epsilon* - H epsilon, giving:

E(test MSE | X) = B2/n + sigma2(1 + (p+1)/n)

Thus expected optimism is 2(p+1)sigma^2/n. For n=120, p=4, B^2/n=0.04, and sigma^2=1:

Expected training MSEExpected test MSEDifference
0.9983331.0816670.083333

These are expectations over repeated samples; a particular realized test MSE can still be below its training MSE.

For RSS=116.4 and sigma-hat-squared=0.96:

  • Corrected test MSE = [116.4 + 2(5)(0.96)]/120 = 1.05.
  • C_p = 116.4/0.96 - 120 + 2(5) = 11.25.

They satisfy sigma-hat-squared(C_p+n)/n = 1.05. With common n and variance estimate, minimizing C_p is equivalent to minimizing corrected test MSE.
