Question 1: Compare KNN and logistic regression

Use data/breast-cancer.csv ...

The simplest workflow is:

  • Load the data.
  • Split into training and test with a fixed random seed.
  • Compute the training means and standard deviations for the three predictors.
  • Standardize train and test using the same values.
  • Fit logistic regression and KNN for each k.
  • Predict probabilities on the test set.
  • Compute ROC curves and AUC values.
  • Compare the AUC values and pick the strongest test model.
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import roc_curve, roc_auc_score

# Load data
path = "data/breast-cancer.csv"
df = pd.read_csv(path)

rng = np.random.default_rng(432)
train_idx = rng.choice(df.index, size=int(0.7 * len(df)), replace=False)
train = df.loc[train_idx].copy()
test = df.drop(train_idx).copy()

predictors = ["mean_radius", "mean_texture", "mean_smoothness"]
X_train = train[predictors].copy()
X_test = test[predictors].copy()

mean = X_train.mean()
sd = X_train.std(ddof=1)
X_train = (X_train - mean) / sd
X_test = (X_test - mean) / sd

y_train = train["y"].to_numpy()
y_test = test["y"].to_numpy()

logit = LogisticRegression(C=np.inf, solver="lbfgs", fit_intercept=True)
logit.fit(X_train, y_train)
logit_prob = logit.predict_proba(X_test)[:, 1]

k_values = [5, 15, 25, 35, 45]
probs = {}
for k in k_values:
    knn = KNeighborsClassifier(n_neighbors=k, weights="uniform", metric="euclidean")
    knn.fit(X_train, y_train)
    probs[k] = knn.predict_proba(X_test)[:, 1]

all_probs = [logit_prob] + [probs[k] for k in k_values]
model_names = ["Logistic regression"] + [f"KNN k={k}" for k in k_values]
aucs = [roc_auc_score(y_test, p) for p in all_probs]

print(pd.DataFrame({"Model": model_names, "Test AUC": aucs}).round(4))

The usual outcome is that logistic regression performs very well and often has the highest test AUC. KNN improves as k increases, but very small neighborhoods are noisy. When the goal is ranking new observations by malignant probability, the model with the best test AUC is the one I would prefer.

Question 2: Training and test ROC curves

Use the same data, split, and standardization as in Question 1. Fit KNN with Euclidean distance, equal neighbor weights, and k in {1, 3, 5, 10, 20}. Use each fitted model to estimate probabilities for both the training and test observations. For training predictions, include each observation itself among its k nearest neighbors.

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import roc_curve, roc_auc_score

path = "data/breast-cancer.csv"
df = pd.read_csv(path)
rng = np.random.default_rng(432)
train_idx = rng.choice(df.index, size=int(0.7 * len(df)), replace=False)
train = df.loc[train_idx].copy()
test = df.drop(train_idx).copy()

predictors = ["mean_radius", "mean_texture", "mean_smoothness"]
X_train = train[predictors].copy()
X_test = test[predictors].copy()

mean = X_train.mean()
sd = X_train.std(ddof=1)
X_train = (X_train - mean) / sd
X_test = (X_test - mean) / sd

y_train = train["y"].to_numpy()
y_test = test["y"].to_numpy()

k_values = [1, 3, 5, 10, 20]
train_auc = []
test_auc = []

fig, axes = plt.subplots(2, 3, figsize=(10, 7))
axes = axes.ravel()

for idx, k in enumerate(k_values):
    knn = KNeighborsClassifier(n_neighbors=k, weights="uniform", metric="euclidean")
    knn.fit(X_train, y_train)

    p_train = knn.predict_proba(X_train)[:, 1]
    p_test = knn.predict_proba(X_test)[:, 1]

    train_auc.append(roc_auc_score(y_train, p_train))
    test_auc.append(roc_auc_score(y_test, p_test))

    fpr_train, tpr_train, _ = roc_curve(y_train, p_train)
    fpr_test, tpr_test, _ = roc_curve(y_test, p_test)

    ax = axes[idx]
    ax.plot(fpr_train, tpr_train, color="#0072B2", lw=2, label=f"Training AUC={train_auc[-1]:.4f}")
    ax.plot(fpr_test, tpr_test, color="#D55E00", lw=2, ls="--", label=f"Test AUC={test_auc[-1]:.4f}")
    ax.plot([0, 1], [0, 1], color="gray", ls=":")
    ax.set_title(f"k = {k}")
    ax.set_xlim([0, 1])
    ax.set_ylim([0, 1])
    ax.set_xlabel("False positive rate")
    ax.set_ylabel("True positive rate")
    ax.legend(loc="lower right", frameon=False, fontsize=8)

axes[-1].axis("off")
plt.tight_layout()
plt.show()

print(pd.DataFrame({"k": k_values, "Training AUC": train_auc, "Test AUC": test_auc}).round(4))

The pattern is the usual one for KNN: at k = 1, the training AUC is almost perfect because each point predicts itself. The test AUC is much lower because it is judged on new observations. As k increases, the training-test gap generally shrinks because the model becomes less flexible and less likely to memorize the training data. If k is too large, the model may smooth over local structure and lose performance.
