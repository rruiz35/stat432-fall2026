Question 2: Ridge regression

Generate the standardized design once with seed 43231. The first two columns are nearly collinear because both are formed from the same latent L_i, so the contrast beta_1 - beta_2 behaves much more noisily than the sum beta_1 + beta_2. Ridge shrinks the unstable direction and stabilizes coefficients.

Using the same repeated noise pairs for the three lambda values, ridge with lambda = 0.02 and 0.2 reduces the empirical variance of the two individual coefficients while leaving fitted values relatively close to the OLS surface, because the shrinkage is applied in all directions but is largest along the unstable nearly-collinear combination.

Question 3: What ridge shrinks

The ridge normal equation is (X^T X + n lambda I) beta_hat = X^T y_tilde. For lambda > 0, the matrix is positive definite and invertible even when X is rank deficient. The fitted response is multiplied by rho_j = d_j^2 / (d_j^2 + n lambda) along each left singular vector direction.

The direction with the smallest singular value receives the strongest shrinkage because its component has the largest relative noise burden. This can reduce prediction variance but can also introduce bias if the signal is truly aligned with that same weak direction.

Question 4: Ridge optimization

The ridge Hessian has eigenvalues a + lambda, so the conditioning improves and the curvature becomes more balanced. Gradient descent contracts each eigendirection by 1 - eta(a + lambda). The stable interval is 0 < eta < 2 / (a_max + lambda). A large eta may fail to converge, whereas a smaller one still converges but more slowly.
