# AI Agent Security in Local Environments

## Question

When an AI agent is integrated directly into a local computer environment (like Copilot in VS Code) with direct access to the file system and development tools, how do security layers like firewalls and access controls interact with and protect against it? Furthermore, could a compromised or malicious local AI agent pose security risks comparable to major incidents like the Canvas hack that affected school districts—where an attacker gained unauthorized access and potentially exposed sensitive institutional data? What are the attack vectors for a local AI agent, and what preventive measures should developers and users implement in educational and professional settings to prevent data exfiltration, unauthorized file access, or lateral movement to other systems?
